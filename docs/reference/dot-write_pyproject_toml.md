# Generate pyproject.toml for a Flower App

Generate pyproject.toml for a Flower App

## Usage

``` r
.write_pyproject_toml(app_dir, recipe, results_dir = NULL)
```

## Arguments

- app_dir:

  Character; path to the app directory.

- recipe:

  A `dsflower_recipe` object.

- results_dir:

  Character or NULL; directory for model/metrics output.

## Value

Invisible NULL.
