# Build the canonical request for one implemented native-tree engine

Build the canonical request for one implemented native-tree engine

## Usage

``` r
.build_native_tree_request(
  engine,
  params,
  features,
  feature_bounds,
  feature_cuts,
  target_name,
  target_levels = NULL,
  target_bounds = NULL,
  schema_sha256 = NULL
)
```
